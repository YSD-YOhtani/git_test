# GitHub研修用 - 電卓アプリケーション

このリポジトリは、GitHub/Gitのハンズオン研修で使用するためのサンプルプロジェクトです。

## アプリケーション概要

簡単な電卓アプリケーション（Java）です。基本的な四則演算を行うことができます。

## プロジェクト構成

```
git_test/
├── README.md
├── pom.xml                 # Maven設定ファイル
├── src/
│   ├── main/
│   │   └── java/
│   │       └── com/
│   │           └── example/
│   │               ├── Calculator.java    # 電卓のメインクラス
│   │               └── Main.java         # エントリーポイント
│   └── test/
│       └── java/
│           └── com/
│               └── example/
│                   └── CalculatorTest.java # テストクラス
```

## 実行方法

### 前提条件
- Java 11以上
- Maven 3.6以上

### ビルドと実行

```bash
# プロジェクトのビルド
mvn compile

# アプリケーションの実行
mvn exec:java -Dexec.mainClass="com.example.Main"

# テストの実行
mvn test
```

## 研修の流れ

### 1. 準備
1. このリポジトリをフォーク
2. ローカルにクローン
3. 新しいブランチを作成（例：`feature/improve-calculator`）

### 2. 課題
以下の修正・改善を行ってください：

#### 課題1: バグ修正
- `Calculator.java`の除算処理にバグがあります。0で割る場合の処理を修正してください。

#### 課題2: 機能追加
- 平方根を計算する機能を追加してください。
- 対応するテストケースも追加してください。

#### 課題3: コードの改善
- コードのコメントを充実させてください。
- エラーメッセージを分かりやすく改善してください。

### 3. Pull Requestの作成
1. 変更をコミット
2. リモートブランチにプッシュ
3. Pull Requestを作成
4. 適切なタイトルと説明を記載

### 4. コードレビュー
1. レビュアーがコードを確認
2. 必要に応じてコメントやリクエストを追加
3. 修正が必要な場合は追加コミットで対応
4. 承認後にマージ
